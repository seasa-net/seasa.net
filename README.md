# SEASA - seasa.net

Corporate site for SEASA (Sistemas de Energía Alternativa y Soluciones Ambientales).

**Stack:** TypeScript · React 19 · Vite · Tailwind v4 · Zustand · Biome

```bash
npm run dev      # dev server
npm run build    # typecheck + production build
npm run lint     # biome check
npm run format   # biome check --write
```
